      Limitaciones importantes. Este análisis solo revisa el formato y los patrones de la dirección. No visita el sitio, no consulta listas de reputación ni servicios externos, y no puede detectar sitios fraudulentos con una dirección de apariencia normal. «Sin indicadores» no significa «seguro». La comprobación con servicios de reputación (por ejemplo, Google Safe Browsing) requiere una clave de API y un servidor, y está documentada para una fase posterior.
